Areas: (b) CI/Actions, (e) Claude Code token efficiency, (a) Godot performance. No earlier reports existed in docs/research/, so nothing was deduplicated against past runs; it was checked against gladiator's workflows (`checks.yml` already shards bot jobs and caches the Godot binary; `android.yml` caches templates; `gpu.yml` has path filters; `.claude/settings.json` sets only concurrency env vars). ## Items

1. **Set a 1-hour cache TTL for subagents and workflows.** Add `CLAUDE_CODE_SUBAGENT_PROMPT_CACHE_TTL=1h` (or `subagentPromptCacheTtl`) to `.claude/settings.json` env in both repos. Subagents, workflows, forks and compaction default to 5 min even on a subscription; the main conversation already gets 1h.
   Payoff: fewer cold-cache rebuilds in fan-outs with long gaps; slightly higher write cost, so measure with `/usage`. Effort S. Who: cloud worker. Source: https://code.claude.com/docs/en/prompt-caching

2. **Use forks, not fresh subagents, when a worker needs the lead's context.** A fork reads the parent's cache on its first request; a fresh subagent always starts cold. Keep fresh subagents (with a cheap `model:` and tight `tools:`) for self-contained jobs and add this rule to `docs/agent_brief.md`.
   Payoff: tokens on context-heavy delegations. Effort S. Who: Curtis/cloud worker. Sources: https://code.claude.com/docs/en/prompt-caching , https://code.claude.com/docs/en/costs

3. **Do not switch model or toggle `opusplan` mid-task.** Each model has its own cache, so a switch re-reads the whole history uncached. Pick model and effort at session start and `/compact` only at task boundaries. On Sonnet 5.5/Opus 5.5 effort changes keep the cache, so effort is the safe knob.
   Payoff: tokens on the weekly limit. Effort S. Who: Curtis. Source: https://code.claude.com/docs/en/prompt-caching

4. **Watch cache hit rate.** `/usage` shows a `Prompt cache (main)` line with the likely cause of the last miss (v2.1.260+); `claude -p "hello" --output-format json` shows `ephemeral_1h` vs `5m` writes. Use it once to confirm items 1-3 help.
   Payoff: finds silent cache-busting (MCP/tool changes, many images). Effort S. Who: Curtis. Source: https://code.claude.com/docs/en/prompt-caching

5. **Cache `.godot/imported` in CI jobs (unverified recipe).** Each matrix job in `checks.yml` runs `godot --headless --import` from scratch. Try `actions/cache` on `.godot/imported` + `.godot/global_script_class_cache.cfg`, key = Godot version + `hashFiles('**/*.import', 'project.godot')`, with a restore-key fallback. No published recipe found, so A/B it on one job and compare wall time; drop it if results differ from a clean import.
   Payoff: seconds-to-minutes per job times every matrix job. Effort S-M. Who: build PC / cloud worker. Source: general Godot guidance only (https://bugnet.io/blog/how-to-fix-godot-resources-failing-to-load-after-cloning-a-project-godot-imported-missing); the cache key is my suggestion.

6. **Preload materials/particles at arena load for stutter on Compatibility.** Official docs say Compatibility (GL 3.3 / GLES 3.0) cannot use ubershaders or pipeline precompilation; the workaround is to show every material, shader and particle system in view for at least one frame during loading (blood FX, gore, sand, weapon materials). Gladiator has a few preload/warm hits in `fighter`, `arena`, `blood_fx`, `sand_surface`; worth auditing that every gore/finisher variant is covered, and add a perf-run check for first-use frame spikes on the RTX 5050 runner.
   Payoff: removes first-hit hitches (gore is rare, so it's the likely worst offender). Effort M. Who: cloud worker + build PC measurement. Source: https://docs.godotengine.org/en/4.6/tutorials/performance/pipeline_compilations.html

7. **Trim PhysicalBone3D count.** Godot's ragdoll docs advise dropping bones too small to matter (fingers, utility bones) since each simulated bone costs. Check the fighter rig for such bones; on Android this is the cheapest physics win. Jolt-specific motor tuning wasn't found in docs (unverified). Payoff: physics CPU on mobile. Effort S-M. Who: cloud worker. Source: https://docs.godotengine.org/en/4.6/tutorials/physics/ragdoll_system.html

One third-party site claims it is active; I found no official confirmation, so treat as not in effect. Hosted runner prices were cut up to 39% in Jan 2026. Re-check the Actions billing page once. Payoff: avoids surprise cost. Effort S. Who: Curtis.
